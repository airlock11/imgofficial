IMG Website — Official multi-sport highlights build

Latest Highlights is supplied only by the Cloudflare /highlights endpoint. The Worker
rotates through official YouTube channels for basketball, volleyball, football, boxing,
MMA, tennis, motorsport, swimming, badminton and table tennis. It has no built-in
videos or fabricated highlight items. The section stays hidden when no verified feed
items are available.
